# Support

## Before opening an issue

1. Install the latest OPlates release using [`INSTALL.md`](INSTALL.md).
2. Verify the client is World of Warcraft 3.3.5a.
3. Confirm `Interface\AddOns\OPlates\OPlates.toc` exists.
4. Reload the UI and reproduce the problem.
5. If possible, test once with unrelated nameplate addons disabled.
6. Search [existing issues](https://github.com/FreakySphere/OPlates/issues).

## Bug reports

Use the [bug-report form](https://github.com/FreakySphere/OPlates/issues/new?template=bug_report.yml). Include:

- the OPlates version;
- client environment: stock, FreakySphere `awesome_wotlk`, or another compatible legacy patch;
- the exact steps that trigger the problem;
- expected and actual behavior;
- Lua error text, screenshots and relevant debug lines;
- whether the issue persists with other addons disabled.

Enable session-only debug logging with `/op debug on`. Disable it with `/op debug off`.

## Feature requests

Use the [feature-request form](https://github.com/FreakySphere/OPlates/issues/new?template=feature_request.yml). Explain the gameplay problem first, then the proposed behavior.

## Security reports

Do not disclose vulnerabilities or sensitive data in public issues. Follow [`SECURITY.md`](SECURITY.md).
