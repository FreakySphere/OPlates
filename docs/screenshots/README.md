# Screenshot Capture Guide

The four PNG files in this folder are intentional placeholders. Replace them with real in-game screenshots using the **exact same names**; no README edit is required.

## Required files

| File | Capture |
|---|---|
| `settings-overview.png` | The OPlates Home page with the navigation rail, header and quick-start tiles visible |
| `nameplates-combat.png` | A readable PvP scene showing both friendly and enemy OPlates icons |
| `class-spec-filters.png` | A Friendly or Enemy Class/Spec Filter window with several entries visible |
| `healer-cc-alert.png` | A Healer CC alert with timer and, if possible, its breaker button |

## Recommended capture style

- Resolution: at least `1200 × 675` (16:9).
- Use the same UI scale for all images.
- Keep the subject centered and leave a little breathing room.
- Use a clean scene without chat spam, debug lines or unrelated windows.
- Hide account names, character names or server details you do not want public.
- Do not expose credentials, private messages or personal data.
- Save as PNG for crisp text.
- Keep each image reasonably compressed for a fast README.

## Final check

Open `README.md` on GitHub after uploading and make sure text remains readable on both desktop and mobile widths.
